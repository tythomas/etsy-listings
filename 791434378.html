DESCRIPTION
Listing is for one 42-piece Homer Laughlin Eggshell Theme china set, dating to 1939.

This set includes service for 6, with each person receiving a complete 7-piece place setting. That complete place-setting structure is an important part of the value, especially for buyers planning a dinner table, tea party, bridal shower, small wedding, or collected vintage event table.

Each place setting includes:
- Dinner plate
- Salad plate
- Bread plate
- Rim soup bowl
- Dessert / berry bowl
- Cup
- Saucer

The china has a beautiful cream ivory color with raised embossed edges and a soft pink rose center design. The overall look is elegant, feminine, and timeless — perfect for a romantic vintage table, cottage dining room, tea party, bridal shower, or event tablescape.

Homer Laughlin’s Eggshell line is loved for its lighter, refined feel, and this Theme shape has wonderful raised detail around the edges. A complete service-for-6 set like this is especially appealing because it is ready to use as a coordinated table setting rather than being a partial mix of pieces.
