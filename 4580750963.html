Description

Vintage circa 1970s tile rummy game with 104 tiles, four racks, die and original instructions in a brown striped carrying case. Case measures 15" x 8 1/2" x 1 7/8".

This vintage number tile game has a great 1970s look, with a brown faux-leather attache-style carrying case accented by green and red stripes. The fitted interior holds the tiles, four brown racks with support pieces, a green die, and the original “Playing Rummy the International Way and American Way” instruction booklet.

The tiles are marked MADE IN TAIWAN. No manufacturer name has been confirmed, so the set is being offered as an unbranded vintage tile rummy game rather than attributed to a specific maker.

CONTENTS
• 104 game tiles
• 4 brown tile racks with support pieces
• 1 green die
• Original “Playing Rummy the International Way and American Way” instruction booklet
• Brown fitted carrying case

The instruction booklet describes play with 106 tiles. This set contains 104 tiles and is therefore missing two tiles from that configuration.

MEASUREMENTS
Case: 15" long x 8 1/2" wide x 1 7/8" deep

CONDITION
Vintage condition with age-appropriate wear. The brown case shows scuffs, scratches and edge/corner wear. The right latch has oxidation/finish loss, the handle has some loose/frayed stitching at one end, and one rear corner has separation/lifting of the covering with the underlying board visible. Tiles show light surface wear/age discoloration. The original instruction booklet has handling and storage wear. Please review all photos closely for condition and the exact pieces included.

A distinctive vintage game set for a game-room display, retro collection, or for anyone who enjoys classic tile rummy games.
